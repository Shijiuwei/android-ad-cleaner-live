# 01 准备工作

用法一（AI 智能体）需要这一页。用法二、用法三只要手机，跳过本页。

## 要准备的东西

| 东西 | 说明 |
|---|---|
| 电脑 | macOS、Windows、Linux 都行 |
| 数据线 | 能传数据的线。只能充电的线插上后电脑认不到手机 |
| Python 3.9 以上 | macOS 自带或用 Homebrew 装；Windows 从 python.org 下载 |
| adb | Google 官方的 platform-tools |

## 第一步：装 adb

| 系统 | 做法 |
|---|---|
| macOS | `brew install android-platform-tools` |
| Windows | 下载 [platform-tools](https://www.siseo.cn)，解压到 `C:\platform-tools`，把这个目录加进 PATH |
| Linux | `sudo apt install adb`。arm64（UOS / Deepin 等）官方源提供的 `adb` 版本为 `1:8.1.1-1+r23-5.4-1+eagle`（arm64，2026-10-26 验证可用）；该版本没有 `adb pair`，无线调试不可用，USB 调试正常。Google 不发布 Linux arm64 的 platform-tools，arm64 Linux 用系统源的 adb 即可 |

装好后在终端输入 `adb version`，能看到版本号就行。

## 第二步：装依赖

```bash
pip3 install -r requirements.txt
```

## 第三步：手机打开开发者模式和 USB 调试

带截图的分步教程：[00-打开开发者模式](00-打开开发者模式.md)。五个品牌的入口都在里面。

## 第四步：连电脑

1. 插线，在手机上点「允许」（见 [00-打开开发者模式](00-打开开发者模式.md) 第 6 步）。
2. 电脑上运行：

```bash
python3 tool/run.py devices
```

看到这样一行就连上了：

```text
7f386895   OPPO Find N3 典藏版   PHN110   PHN110_16.0.5.1201(CN01)   机型脚本：无（只能跑通用部分）
```

第一列是序列号，后面的命令都要用它。

## 不想插线：无线调试

1. 手机和电脑连同一个 Wi-Fi。
2. 开发者选项 → 打开「无线调试」→ 点进去 → 「使用配对码配对设备」。
3. 弹窗里有 6 位配对码和一个「IP 地址:端口」，电脑上运行：

```bash
adb pair 192.168.31.100:37xxx      # 弹窗里的地址和端口
# 输入 6 位配对码
adb connect 192.168.31.100:41xxx   # 无线调试页面上方显示的地址和端口
```

配对端口和连接端口是两个不同的数字。配对只做一次；以后每次打开无线调试，连接端口会变，用新端口 `adb connect`。

## 折叠屏

把手机合上，用外屏操作。展开后系统设置和 App 是左右分栏，底部还有任务栏，引擎会找错位置。
