# 03 用聊天 AI 带你点

适合：只有手机，没有电脑。
原理：聊天 AI 不能操作你的手机，它读清单，一步一步告诉你点哪里；你点完回复它，或者发截图给它看。

## 三步开始

1. 打开 DeepSeek、豆包、ChatGPT 中的任意一个。DeepSeek 要打开「联网搜索」，豆包和 ChatGPT 默认能读链接。
2. 复制 [prompts/聊天AI提示词.md](../prompts/聊天AI提示词.md) 里方框中的整段文字，发给 AI。
3. 回答 AI 的问题：品牌、型号、系统版本。

型号和系统版本在这里看：

| 品牌 | 路径 |
|---|---|
| OPPO / 一加 / realme | 设置 → 关于本机 |
| 小米 / Redmi | 设置 → 我的设备 |
| vivo / iQOO | 设置 → 系统管理与升级 → 版本信息 |
| 荣耀 / 华为 | 设置 → 关于手机 |

## 对话长这样

```text
AI：你的手机是什么品牌和型号？系统版本是多少？
你：OPPO Find N6，ColorOS 16
AI：第 1 步：打开「设置」→「隐私」→「设备标识与广告」→「广告跟踪」。
    这一页每个 App 有一个开关，全部关掉。关完回复「好了」。
你：好了
AI：第 2 步：从桌面左边缘向右滑，打开负一屏……
```

## AI 读不了链接时

1. 打开 [docs/清单/](清单/)，找到你的品牌。
2. 点开清单文件，全选复制。
3. 粘贴给 AI，说「按这份清单带我做」。

## 和用法一比

| | 用法一：AI 智能体 | 用法二：聊天 AI |
|---|---|---|
| 要电脑 | 要 | 不要 |
| 谁点屏幕 | 脚本 | 你 |
| 用时 | 4 到 6 分钟（有机型脚本） | 30 到 60 分钟 |
| 能挂起广告包 | 能 | 不能（要 adb） |
| 能批量关营销通知 | 能 | 不能，一个个关 |
