## 与 18 Pro Max / 18 Fold 的四处差异

1. **广告服务在「安全」分栏 →「更多安全设置」页底**（要先滑过「用户体验改进计划」），「隐私」分栏里没有这一项。它本身是 `com.android.settings.ad.AdServiceSettings`，`am start` 直达后这段从 50 秒降到 2 秒。
2. **这一页会让引擎误点一次开关**：开关说明是「**关闭**后，广告数量不会因此减少……」，`p.start()` 启动后的弹窗清理按「关闭」找 ✕，会把整行 `content-desc` 当成关闭按钮点一下，等于自己拨了一次开关。脚本改用 `am start` 直达、不经过 `p.start()`。引擎侧的 `dismiss()` 误点已由 [#378](https://github.com/rddmwmddr/android-ad-cleaner/issues/378) 承接；#305 已把 `gear()` 的「设置」改成精确匹配。
3. **主题商店的齿轮先命中「设置壁纸」**：`设置壁纸` 的 desc 也含「设置」，按包含匹配会先进壁纸页。脚本的 `gear()` 只认正好是「设置」的描述 / 正文（#305 / #374）。
4. **应用商店的「个性化服务」是子页入口**（隐私页本身没有开关）；**浏览器关闭「个性化内容推荐 / 个性化广告推荐」各弹一次「关闭提醒」**，必须点「确认关闭」，点「以后再说」等于没关。浏览器工具栏的齿轮点进去是「页面布局 / 快捷网址 / 全网热榜」，主设置页是 `com.android.browser/.BrowserSettingsActivity`，脚本直达它。

## 同一台机器上顺带测到的其他功能（不属于本机型脚本）

- `chan-scan` 21 个候选，按 AGENTS.md §5 剔掉 2 个服务类（币安「直播」= 关注的人开播提醒、盼之账号「运营通知」含义含糊），关闭 19 个，112 秒，复查「营销渠道仍开着: 0 个」。
- `suspend com.miui.systemAdSolution`：挂起成功，同时禁止联网。
- `quickapp off`：`com.miui.hybrid` 已关闭（关闭前在后台运行）。
- `finish`：插电常亮已改回 `0`。

## 边界

- 九段脚本的关闭动作由报告者在其机器上完成；本仓库只验证了规则与入口的写法，没有真机执行记录。
- 报告者的复跑是在目标已关闭状态下做的，核对数不等于实际新关掉的数量。
- 合并后用新版本在 M332BF 上复测，通过后再关闭 [#374](https://github.com/rddmwmddr/android-ad-cleaner/issues/374)。
