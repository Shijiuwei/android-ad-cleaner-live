## 实测结果

- 系统广告段完成真实“开启→关闭”：无线 39 秒，调整 1 项；有线原生 28 秒，调整 1 项，均回读确认关闭。
- 用 Xiaomi 18 Pro Max 参考脚本（OS4.0）在 K70 上按安全模式跑完 9 段，共调整 14 项：应用商店 1、下载管理 2、主题 2、全局搜索 8、负一屏 1。
- 按 K70 实际入口补充浏览器、天气、日历三段，实际关闭 5 项：浏览器 2、天气 2、日历 1。
- 应用商店在标准模式下单独复跑：37 秒，核对个性化服务和通知设置各 1 项，调整 0 项、步骤异常 0 个；跑前后都保持标准模式，未切换到极简模式。
- 9 段专用脚本在目标已关闭状态下完整复跑：无线阶段（移除小说前）307 秒；最终脚本在有线原生 1440×3200 上 230 秒；两次均为 0 调整、0 步骤异常。

本轮验证还曾关闭浏览器「小说」功能入口；因其不是广告开关，已从最终脚本移除。手机上的该项仍为关闭；当前脚本目标为 20 项，本轮实际关闭 21 项。

## 专用脚本入口

- 系统广告：设置 → 隐私与安全 → 上方「安全」标签 → 更多安全设置 → 广告服务。
- 应用商店：我的 → 设置 → 隐私/通知设置；关个性化服务（其他版本叫个性化推荐）和「新手帮助」，不碰推送消息和应用更新。
- 手机管家：设置 → 隐私设置/垃圾清理。
- 下载管理：更多/齿轮 → 信息流设置。
- 主题：我的 → 设置/隐私设置。
- 浏览器：我的 → 设置 → 主页设置（宫格位推送）/搜索设置（显示猜你想搜模块）；「最新资讯」在 20.28.1020918 为 disabled。
- 全局搜索：设置 → 首页展示模块/热搜榜单。
- 负一屏：设置 → 推荐卡片/热门活动/隐私设置。
- 天气和日历：天气「更多设置 → 设置 → 用户体验计划」；日历先点底部菜单「设置」，再点弹窗里的「设置」，滚动到底进入「用户体验计划」。
