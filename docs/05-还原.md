# 05 还原

| 改动 | 还原方法 |
|---|---|
| 挂起的广告包 | `python3 tool/run.py -s S unsuspend`（解除记录里的全部） |
| 单个包 | `python3 tool/run.py -s S unsuspend com.opos.ads` |
| 营销通知渠道 | `python3 tool/run.py -s S chan-on backups/<型号>-<时间>/channels.tsv` |
| 快应用 | `python3 tool/run.py -s S quickapp on`；vivo 服务开关按本设备保存的原值恢复，无备份时不默认开启 |
| 插电常亮 | `python3 tool/run.py -s S finish` |
| App 内的开关 | 按 [清单](清单/) 里的路径手动打开 |
| 小米 msa 断网 | 见 [清单/小米-HyperOS.md](清单/小米-HyperOS.md) 末尾 |

还原要用电脑。开发者模式关掉了的话，按 [00-打开开发者模式](00-打开开发者模式.md) 重新打开。

## 没有电脑时还原挂起的包

挂起的 App 图标是灰色的，点开会提示「已暂停」。挂起状态要用 adb 解除，没有电脑时：

1. 恢复出厂设置会解除挂起（数据会清空，要备份）。
2. 或者借一台电脑，装 adb，运行 `adb -s S shell pm unsuspend --user 0 包名`。

## 改动前的快照

`backup` 存的快照在 `backups/<型号>-<时间>/`：

| 文件 | 内容 |
|---|---|
| `info.txt` | 品牌、型号、系统版本 |
| `sys.txt` `user.txt` `disabled.txt` | 系统应用、自装应用、已停用应用 |
| `settings-before.txt` | 系统设置项全量 |
| `notif.txt` | 通知渠道全量 |
| `stay_on.txt` | 插电常亮的原值 |
| `channels.tsv` | 这次关掉的营销通知渠道 |
| `suspended.txt` | 这次挂起的包 |
| `quickapp-setting.json` | vivo 快应用服务开关的原值及所属设备；还原成功后删除，重复关闭和新建快照不会覆盖初始记录 |

想知道某个设置改没改过，用改动后的 `settings list` 和 `settings-before.txt` 对比。
